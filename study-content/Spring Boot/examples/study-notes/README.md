# Spring Boot vertical slice
Java 17 baseline, Spring Boot 3.1.3, dependency-management plugin 1.1.3.
With compatible Gradle 8.x run gradle test and gradle build; run gradle bootRun on loopback port 8000.
This source-pinned teaching slice intentionally demonstrates create/list/read and safe errors.
The repository is in memory. It is not a complete authenticated hosted capstone.
The later lessons specify update/delete, persistence, ownership, migrations, and production checks as labs.
Generate a Gradle wrapper locally when Gradle is available. Do not copy the app Android wrapper blindly.
